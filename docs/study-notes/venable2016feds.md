# Critical reading: venable2016feds

DOI: https://doi.org/10.1057/ejis.2014.36

Local full text: [PDF](../studies/venable2016feds.pdf) — 13 PDF pages.

Reading date: 16 October 2026.

Complete article including both illustrations, applied case, limitations and references read. Methodological research essay, not BCM software. FEDS separates functional evaluation purpose (formative/summative) from evaluation setting (artificial/naturalistic), and proposes four strategy families (pp.4–7).

The four planning steps specify goals, choose strategy, identify properties and design individual evaluation episodes (pp.6–8). Two existing DSR studies illustrate classification, and an applied game-design DSR project provides evidence of utility (pp.9–11). Limited cases constrain generalization; FEDS is a planning framework rather than a standard quantitative effectiveness instrument (p.12). Real users handling hypothetical cases do not by themselves constitute fully naturalistic deployment.

Masar implication: separate technical rule verification, practitioner comprehension and comparative task performance. Early synthetic cases test efficacy under explicit assumptions, later user tasks assess bounded usefulness. No actual implementation or participant evaluation is claimed during IS595. Outcome measures should match traceability and task claims, rather than imply reduced incident downtime.
